# Glass Effect Calculator 🧮✨

A stylish calculator web app with a **glassmorphism UI** built using **HTML**, **CSS**, and **JavaScript**. This project demonstrates clean design and basic arithmetic functionality with a modern aesthetic.

## 🔗 Live Demo

[View Live](https://prakashrpk.github.io/calculater-glass-effect-using-html-css-js/)  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (with glassmorphism effect)
- **JavaScript** (for calculator logic)

---

## 📋 Features

- Beautiful glassmorphism design (blur, transparency, soft borders)
- Supports basic arithmetic operations: `+`, `-`, `*`, `/`
- Responsive layout (works on desktop & mobile)
- Interactive buttons with hover and click effects
